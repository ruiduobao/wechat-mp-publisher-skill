## 2026-11-12 独立测试反馈与修复

独立验收会话在 `8956eb6` 上执行测试，确认零正文图稿（`100021900`）全部通过，并定位到两项真实体验与验证阻断：
1. **专用浏览器未运行时需人工重启**：`connectOrCreateHomeSession` 未能自行拉起专用 Profile 浏览器。
2. **微信去重/重签名 CDN URL 误判**：`100021855`（6图玛雅稿）独立像素交叉 MAE（≤ 0.002）与文字均完全一致，但重开读回的 qpic 路径被微信替换，导致严格字符串相等比较误判 `FAIL`。

同时在 2026-11-13 实战运行中发现并修复：
3. **`--refresh-content` 更新已有草稿时粘贴轮询误读旧正文**：只检查非空文本导致偶发提前读到旧正文而丢失占位符。现改为轮询直到整篇规范化文本真正匹配待粘贴新正文。
4. **多图连续上传时一次选区抖动直接失败**：`locatePlaceholderAndSetAnchor` 现支持最多 3 次重新激活/重设选区重试，依然严格经 `Input.insertText` 替换并比对整篇文本，绝不直接改 DOM。
5. **高频操作提速与便捷 CLI**：新增 `--search`、`--latest` 和 `bun run titles`；将多处固定长等待改为状态驱动轮询，并支持找不到专用浏览器端口时以独立脱管进程安全自启专用 Profile（不杀用户其它 Edge）。
