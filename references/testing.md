# 测试与独立验收

把验收分成三类，分别报告结果。离线回归证明代码分支可按预期运行；只读预检证明来源和映射可计算；真实保存后重开证明本次微信编辑器接受了修改。三者不能互相替代。

## 1. 离线回归

在仓库根目录执行：

```bash
bun install --frozen-lockfile
bun run typecheck
bun run test
```

测试使用合成 Markdown、临时状态库和模拟 CDP。记录实际命令、退出码、测试数、源码提交及工作区是否有改动。仓库增加测试后，旧的固定“137项通过”不能当成本次结果。

关注的回归场景：

| 场景 | 必须观察到的结果 |
|---|---|
| 正文中英文、括号、空格路径及重复图片 | 路径正确，每次引用独立定位 |
| 图片示例位于代码块 | 不误识别为待上传图片 |
| 未收到可信 HTML 粘贴 | 失败，不能用 DOM 内容冒充成功 |
| 替换图片占位符 | 输入选区准确，旧占位符消失，文字通过编辑器输入改变 |
| 旧图、远处其它图片或图片未加载 | 拒绝当成本次上传成功 |
| 标题结构错误、重复 H1 | 阻断元数据修补并提示完整重建 |
| 隐藏正文、图片消息 | 写入前停止，保留原稿 |
| 坏 JSON、缺图、源文件暂时消失 | 保留既有 ID，明确诊断 |
| 元数据修补通过 | 不推进完整正文应用指纹 |
| 保存成功但重开失败 | 保留 ID，标记未验收 |
| 并发进程持锁 | 另一进程不得开始写入 |

模拟器会漏掉真实编辑器选区同步、微信自动保存和浏览器解码时序，所以修复输入代码后仍需网站实测。

## 2. 只读预检

```bash
node bin/launch-publisher.mjs --help
node bin/launch-publisher.mjs --check
node bin/launch-publisher.mjs --check --titles "C:/private/titles-override.json"
```

独立测试者应记录运行前后历史与基线哈希、锁是否存在；确认没有创建浏览器标签或写入来源。可以对隔离的临时来源和临时状态路径使用环境变量，不要清理真实历史来制作测试场景。

预检没有短标题时应给出可操作的 `needs-title` 诊断并继续列出其它文章。正式编辑仍要求新外题合规，不能以预检可列出长题为由放宽写入。

## 3. 独立子 agent 的真实测试

用户授权真实草稿测试后，由未参与实现的子 agent 按更新文档操作。主 agent 在测试开始后暂停浏览器写入与生产代码修改，避免相互抢焦点或让证据对应不上源码。

建议使用两个已确认映射的普通长文：

- 多图文章：验证完整内容原 ID 更新、逐图上传、正文一致性和名片。
- 零正文图文章：验证完整正文原 ID 更新，并复用有效独立封面；正文保持零图。

为避免制造测试副本，优先选已有草稿，使用 `--refresh-content --id`。ID、文章标题、源路径和真实内容留在私有测试报告里。测试标签由本任务创建并关闭，不碰用户标签。

测试者须自己读取 `SKILL.md`、[operations.md](operations.md)、CLI 帮助和当前状态，不依赖主 agent 的“已成功”描述。建议测试指令如下：

```text
按仓库文档对两个已确认普通长文执行独立测试。
先做只读预检和类型检查，再逐篇原 ID 完整更新。
禁止发表、群发、删除草稿，禁止修改 F:/Z: 来源。
每篇保存后从独立标签重开同一 ID，记录完整验收项。
若失败，报告实际失败阶段、是否已取得或自动保存 ID、是否保全；不要降低检查标准。
报告使用的源码提交与工作区改动、命令、退出码、每项证据、结论和覆盖不到的能力。
```

至少一个测试需要真正发生保存。命中 `SKIP` 后看到“0任务”只证明幂等跳过，不是保存链成功。验证失败项修复后，让同一个独立测试者重新执行受影响场景并给出第二次结论。

## 4. 真实验收矩阵

| 检查项 | 多图稿 | 零图稿 |
|---|---|---|
| 使用原有同一 appmsgid | 必须 | 必须 |
| 正文首位完整唯一 H1 | 必须 | 必须 |
| 作者、外题正确 | 必须 | 必须 |
| 正文文字前后相同 | 必须 | 必须 |
| 图片身份、顺序、加载 | 全部图片 | 图片数量保持0 |
| 封面保存后存在 | 必须 | 独立封面必须保留 |
| 正确原生账号名片居尾 | 必须 | 必须 |
| 无占位符及定位标记 | 必须 | 必须 |
| 状态库只在对应模式推进指纹 | 必须 | 必须 |
| 重复只读预检 | 对该篇0待处理 | 对该篇0待处理 |

复用已有封面只覆盖“保留封面”，不覆盖“首次上传、选图、裁剪”。图片消息拒绝测试只覆盖停止能力，不覆盖转换图片消息为普通长文。

## 5. 报告与发布

私有报告建议写到 `tests/reports/`，日志脱敏。公开文档可记录测试日期、提交、离线计数、实际测试范围及局限；不要复制真实草稿映射、原文、截图、原生名片模板、token、Cookie 或凭据。

推送前检查暂存差异、文件清单和私有文件忽略规则。推送后用远端分支引用核对实际提交，不能把 `push --dry-run` 当成已推送。若子 agent 被模型服务商拒绝，报告该环节未完成，不把主 agent 自测写成独立验收。
