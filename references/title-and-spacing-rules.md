# 标题精炼与防空行排版规则

## 一、标题必须 ≤ 15 个汉字准则

微信公众号后台标题上限为 64 字，但在手机订阅号列表、图文卡片和消息通知中，超过 15~18 个汉字时后半部分就会被 `...` 截断。为了确保科技推文的成果、机构与技术点在一眼内清晰展现，制定了 **≤ 15 字严格精简规则**：

### 1. 过滤要素
- 剔除前置分类与期刊前缀（如 `【RSE顶刊】`、`01_`、`Nature Communications：` 等）；
- 剔除冗余修饰词（如“突破重磅提出”、“打破纪录”、“大模型赋能”、“重磅发布”等）；
- 剔除所有全角/半角标点符号（标点占用视觉宽度且容易造成折行碎片化）。

### 2. 精简范例对齐表

## 二、全流程防空行排版净化机制

微信公众号富文本编辑器（ProseMirror）对于换行有着极其严苛的渲染行为：普通的 Markdown 换行如果不加处理，会转换成额外的 `<p><br></p>` 或 `margin` 重叠，导致文章在手机端阅读时出现大片突兀的空白。

本项目采用了**三道拦截网**彻底消灭空行：

### 1. Markdown 源码净化
- 清洗多余空行：将 `\n{3,}` 统一合并为 `\n\n`；
- 行尾空白字符剔除：`/[ \t]+$/gm`；
- 引用块（`>`）与列表项（`- `）之间的非必要空行自动折叠。

### 2. HTML 标签净化
- 过滤渲染产物中空容器：
  ```regex
  /<p>\s*(<br\s*\/?>|&nbsp;|\s*)*<\/p>/gi -> ''
  /<div>\s*(<br\s*\/?>|&nbsp;|\s*)*<\/div>/gi -> ''
  ```

### 3. 编辑器原生 DOM 深度清洗
在 HTML 注入到编辑器节点后，立即在浏览器上下文中通过 CDP 执行深度清洗：
```javascript
const paras = Array.from(editor.querySelectorAll('p, div'));
for (const p of paras) {
  const text = p.textContent.replace(/[\s\u00a0\u3000]/g, '');
  const hasMedia = p.querySelector('img, picture, svg, video, iframe, [data-wechat-image]');
  if (text === '' && !hasMedia) {
    p.remove(); // 直接从富文本树中移除该空容器
  }
}
```
保证最终文章段落紧凑、排版专业，行间距均匀自然。
